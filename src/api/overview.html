Diwan Database is a Java port of Laravel's database layer: query builder, schema builder, migrations, seeding and Eloquent-style models. Guides and tutorials are on the documentation site.

  • Core (org.aristonis:diwan-database): connections, query and schema builders, migrations, seeding.
  • SQLite (org.aristonis:diwan-database-sqlite): the SQLite driver.
  • PostgreSQL (org.aristonis:diwan-database-pgsql): the PostgreSQL driver.
  • Eloquent (org.aristonis:diwan-database-eloquent): models, relations, casts and scopes.
  • Android (org.aristonis:diwan-database-android): a driver over Android's SQLiteDatabase.
  • Testing (org.aristonis:diwan-database-testing): a JUnit 5 extension and database assertions.
